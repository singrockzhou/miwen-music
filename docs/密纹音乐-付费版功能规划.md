# 密纹音乐 · 收费版本功能规划建议

> 前提：免费版即当前已交付的 1.0（本地曲库、播放内核、歌单收藏、三主题、断点续播）。
> 收费版**不改变**四条定位红线：单机、离线、无账号、零广告。
> 本文只回答三个问题：**卖什么、怎么切、什么时候卖**。
>
> **2026-11-24 修订**：原计划把「10 段图形 EQ」当 Pro 头牌，真机验证后**否决**。
> 鸿蒙 SDK 对第三方只开放 `AudioEffectMode` 两态（`EFFECT_NONE` / `EFFECT_DEFAULT`），
> 没有 `AudioEffectManager`、没有频段增益 API。Pro 的门面改为「直出模式」。
> 详见第七节，以及随附的《密纹音乐-Pro版技术验证.md》。

---

## 〇、先看技术验证结论（这决定了卖什么）

| 项 | 结论 | 证据 |
|---|---|---|
| 10 段 EQ / 参数化均衡器 | **做不了**（不引入 Native 解码播放链的前提下） | 全 SDK 无 `AudioEffectManager` / 频段增益接口；`AudioLoopbackEqualizerPreset` 只作用于耳返 |
| 系统音效开关 | **能做，且已做** | `AVPlayer.audioEffectMode` 两态可写，真机 `audioEffectMode=NONE` 已生效 |
| 直出（旁路系统音效） | **可卖** | 真机日志 `prepared → audioEffectMode=NONE → playing` |
| 自建 AudioRenderer + Native EQ | 理论可行，成本 XL | 等于重写播放内核（解码、seek、长时任务、AVSession 全要重做） |

**一句话**：这款 App 的 Pro 不卖"调音"，卖"还原"。文案上不能叫均衡器，只能叫直出——这反而是更硬核的卖点。

## 一、先定商业模型：卖"能力"而不是卖"时间"

| 方案 | 形态 | 优点 | 致命问题 | 结论 |
|---|---|---|---|---|
| A. 订阅制 | 每月 ¥6 解锁全部 | 收入可复利 | 与"一次买断"定位直接冲突；离线播放器做订阅，用户第一反应是"我本地歌凭什么月付" | 否 |
| B. 功能包 DLC | 解码包 ¥12 / 音效包 ¥12 / 主题包 ¥6 | 门槛低、可按需买 | 拆得太碎，用户要算账；后续加包像"无限追加付费"，口碑差 | 否 |
| C. 单档 Pro 买断 | 一次性解锁"发烧友工具集" | 与定位同频、话术干净、复购靠口碑 | 需要一次性做厚功能，前期投入大 | **推荐** |
| D. 免费版限量 | 免费限 300 首，Pro 无限 | 转化最狠 | 用户会把"限曲目数"当勒索；差评集中点；且技术上限容易绕 | 否（可作备选埋点，不建议首发） |

**结论：C 单档买断**，命名为「密纹 Pro」，一句话卖点：
> 一次买断，永久可用，不加订阅、不联网校验、不收集任何数据。

### 落地时必须解决的一个冲突：支付本身要联网

鸿蒙上数字商品**必须**走华为应用市场 IAP（`@kit.IAPKit`，非消耗型一次性商品），不允许自建支付。
这意味着"零联网"需要补一条精确表述：

> 除**购买**与**恢复购买**这两个动作外，App 不发起任何网络请求。购买凭证本地缓存，之后永久离线可用。

这条要写进应用市场详情页和设置页的"零联网说明"，否则会被用户当成虚假宣传。技术上：首启不联网、播放不联网、`queryOwnedPurchases` 只在用户主动点"恢复购买"时调用一次。

## 二、卖什么：按"付费意愿 × 实现成本"分四象限

（见随附矩阵图）

### 第一梯队 · 门面功能（高意愿 × 中低成本，Pro 首发必须有）

> 会让免费版显得"残缺"，正好踩中本文第三条红线。真正的付费理由应该是解码、CUE、无缝、

>
> 结论：Pro 的卖点从 6 条收敛到 5 条，价格策略不变（少一条不降价，因为这一条本来成本是 S）。

## 三、怎么切：免费与 Pro 的分界线

**三条红线（破了就等着被差评）：**

1. **不缩减已有免费功能**。1.0 已经能做的事，2.0 不能变成"Pro 专享"。
2. **不限制播放**。不限曲目数、不限时长、不限次数、不插页。
3. **不锁基础体验**。播放/暂停/切歌/进度/歌单/收藏/断点续播/三种主题（保留免费的暗夜+白纸，Pro 才是"全部主题"）永久免费。

**建议的切法（按"专业度"切，不按"使用量"切）：**

| 维度 | 免费版 | Pro |
|---|---|---|
| 格式 | MP3 / FLAC / WAV / AAC / OGG | + ALAC / AIFF / APE / WavPack / DSD |
| 曲库组织 | 按标签 + **目录树 + 多根目录**（1.1.0 起免费） | + CUE 分轨 |
| 音质 | 系统默认 | EQ、音量归一化、无缝播放、变速不变调 |
| 主题 | 暗夜 + 白纸 | + 磁带 + 黑胶 + 夜航 + 牛皮纸 + 高对比 |
| 歌词 | 同名 .lrc | + 内嵌歌词、双语、偏移微调、桌面/锁屏歌词 |
| 数据 | 无 | 备份还原、M3U 导入导出、统计报告 |
| 系统集成 | 2×2 卡片 | 全尺寸卡片矩阵、桌面歌词 |

原则：**免费版是一个"体面的完整播放器"，Pro 是"给发烧友的第二套工具"**。不制造残缺感，只提供进阶感——这样负面评价的概率最低，而愿意为"我这种人终于有人做了"付钱的人一定会付。

## 四、付费墙怎么摆（不打扰的前提下提高转化）

1. **入口只有一个半**：设置页顶部一张"密纹 Pro"卡（露出已购状态）+ 遇到 Pro 功能时的就地提示条。不做开屏广告式弹窗。
2. **先体验再买**：Pro 功能在免费版**可见、可点、可用 3 次**（如 EQ 试 3 次），第 4 次弹购买面板。发烧友摸过 EQ 才知道值不值。
3. **就地说明，不跳转**：点锁图标打开 `ActionPanel`（复用现有组件），三行讲清"买断 / 永久 / 不联网"，底部一个"去购买"和一个"以后再说"。
4. **重要：不能靠远程埋点算转化**。零联网意味着拿不到自建埋点，只能：
   - 用应用市场后台的"下载量 / 付费量 / 退款率"反推；
   - App 内做一个"本地使用概览"（听歌时长、格式分布、Pro 入口点击数），用户反馈问题时截图带出来。
   这一点要在做付费前就想清楚，否则会做出一个"上线后完全不知道转化漏斗"的黑盒。

## 六、什么时候卖：三段路线

### Pro 1.0（v1.1，**七项已全部实装并真机验收**，Pro 1.0 梯队清零）
直出模式、主题包（磁带/黑胶/夜航/牛皮纸/高对比——磁带 v1.7.0 起划入 Pro）、歌词增强（内嵌 / 双语双行 / ±0.5s 调轴）、
M3U·M3U8·PLS 导入导出 + 整库备份还原、A-B 循环、听歌统计（含存成长图）、卡片矩阵（封面密度三档）。
每一项都带 3 次试用门槛（数据页走面板，播放页/密度档直扣并 toast 次数）。

- 这一档**全部是 ArkTS 层可完成**的功能，不引入 Native，风险最低，用来验证"到底有没有人买"。
- 首发即收费，价格用早鸟 ¥18。

### Pro 1.5（v1.2，**四项已实装并真机验证**，1.2.2 补齐分轨歌词偏移后无已知功能缺口，见《真机验证报告》第十一节）
CUE 分轨、无缝播放 gapless、交叉淡入淡出、桌面/锁屏/播控歌词、全格式识别层（APE/DSD/WavPack/AIFF 扫得进、点播给明确话术）。

- 实装口径：**CUE 分轨、无缝切流、交叉淡入淡出、桌面歌词（API 26 原生 AVSession）、识别层拦截话术**全部真机跑通。
  桌面歌词逐行高亮在修掉「逐行推送把 duration 冲空」后确认跟随（报告 11.3）；淡入淡出为 3 秒双向包络。
  分轨歌词按 `cueStart` 裁窗平移（1.2.2），第 2/3 轨不再唱第 1 轨的词。
  仍欠**听感回采**（不回采波形就无法断言听不出缝）与锁屏歌词逐屏核对。
- **真解码顺延 Pro 2.0**：ALAC / AIFF / WavPack / APE 的 NAPI 解码链、DSD/ISO 直读与 DoP 输出没有进这一版，
  本版只保证「扫得到、看得见、说得清为什么播不了」。规划里的「+8–15 MB 包体」因此并未发生，包体不变。
- 这档产品价值仍在：分轨与无缝解决「听现场专辑卡一下」的硬痛点，桌面歌词是鸿蒙上极稀缺的能力。
- 价位按原计划：Pro 1.5 早鸟 ¥28。

### Pro 2.0（v2.0，进行中）
APE / ALAC / AIFF / WavPack 的 NAPI 解码、DSD（dsf/dff）/ ISO 直读、DoP 输出链与硬件提示、变速不变调 0.5–2.0×。

- **v1.3.0 已落地第一块：自建解码链 + AIFF/AIFC 真播**
  （`cpp/` + `libmiwen.so`，NAPI 导出 `open/read/seek/close`，PCM 以交错 float32 喂 AudioRenderer）。
  这条链打通后，剩下三种格式只是"在 `fmt_*.cpp` 里加一个解码器 + 在 `CreateSource` 加一条分派"，
  不必再动播放器、进度、焦点、直出这些外围——那些已在 AIFF 上验证过。
- 仍按格式逐个接：WavPack（BSD）、ALAC（Apache-2.0）、APE（Monkey's Audio，授权需先核实）。
  每接一种，就把它从 `Constants.UNDECODED_SUFFIX` 移入 `NativeHandlesSuffix`，两处口径必须同步。
- 变速不变调（第二梯队第 9 项）顺延到这里：AVPlayer 的 `setSpeed` 会一起变调；
  但自建链已能拿 PCM，变速可改为在 native 侧重采样（SoundTouch/Rubber Band）。
- DSD 与 APE 是「要不要投」的决策点：**先看 Pro 1.5 的销量**再决定，不要一开始就承诺。
- 价位在这个阶段从 ¥28 提到 ¥38 才站得住。

## 八、三个需要提前决策的风险

1. ~~**EQ 能不能挂上 AVPlayer，是全盘关键**~~ → **已定论（2026-11-24）**：挂不上，且不是"换个写法就好"的问题——系统没有开放频段增益通道。原计划里的 EQ 已从 Pro 清单撤下，换成直出模式。若坚持要 EQ，唯一路径是 AudioRenderer + Native 解码自建链路（XL），不建议在 Pro 1.x 阶段碰。
2. **付费即联网，与"零联网"叙事有摩擦**。必须在详情页与设置页把"仅购买时联网"讲成一句诚实的说明，不要装作完全离线。
3. **零联网 = 拿不到转化数据**。上线前就要接受"只能看市场后台销量"的现实；不要为了看数据偷偷加统计上报——那会一次性摧毁这款 App 唯一的信任资产。
4. **重装即丢目录授权**。`FILE_ACCESS_PERSIST` 的授权在重装后失效，曲库索引还在但 `fs.open` 全返回 `13900001`，表现为"歌单里每首都点不动"。这不是 bug，但**必须在错误提示里给"重新选择目录"的指引**，否则用户会以为 App 坏了（真机验证时就踩到了）。
