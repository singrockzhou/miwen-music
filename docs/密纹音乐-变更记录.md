### 一、新增功能

#### 1. 磁带主题挪入 Pro（核对偏差 #1 整改）
- `Theme.ets`：`FREE` 数组收敛为 `[DARK, PAPER]`，磁带从免费档挪出；未购拦截复用既有启动回退（`isPro(tk) && !ProService.isPro()` → 回退暗夜），不新增门禁代码。
- `SettingsView` 外观文案更新为「后五套为密纹 Pro 主题。磁带是拟物怀旧档……」；`ProPage` 主题包描述补磁带。

#### 2. 多声道 SACD 区（核对缺口 #2 整改）
- `fmt_iso.cpp`：`ParseSacdIso` 支持 MULCHTOC——area1 优先、无 area1 用 area2（多声道区），立体声区解析失败回退多声道区；channelCount 放宽 1–6（原 >2 拒绝，`fmt_dsd.cpp` DFF 侧同步放宽）。
- `NativePlayer.ets`：renderer 恒双声道（CHANNEL_1/CHANNEL_2），`fill()` 对 channels>2 做 downmix——ch0/ch1 取源 L/R 基底，其余声道按 0.5 幅度同混进两侧，clamp ±1；trackLevel 按 downmix 后数据统计。解码链（SacdFeeder/Decimator/FrameBitSource）天然声道参数化，零改动。
- 素材工具 `tools/dsd_material/make_sacd_mch_iso.py`：生成 MULCHTOC 5 声道测试 ISO（SACDText 专辑名 Shift-JIS、曲名 GB2312，兼验编码），内置 verify_iso 与 fmt_iso 解析逻辑镜像、bit-exact 通过。

#### 3. ISO 标题编码 GB2312 / Shift-JIS（核对缺口 #3 整改）
- `fmt_iso.cpp`：CleanText 升级为 `DecodeIsoText`，探测顺序 UTF-16LE BOM > 纯 ASCII > 合法 UTF-8（含多字节合法性、过短编码与代理区检查）> Shift-JIS（严格 lead 0x81–0x9F/0xE0–0xEF + 半角假名 0xA1–0xDF，须含 ≥1 双字节）> GB2312（严格 lead 0xA1–0xF7、trail 0xA1–0xFE）> Latin-1 逐字节兜底。三处调用点（album/artist/title）统一走它。
- 码表自生成：`tools/dsd_material/gen_charset_tables.py` 从 Python codecs 生成 `charset_tables.h`（SJIS 7336 对 + GB2312 7445 对，`{u16 码位, u16 码点}` 升序数组），运行时二分查找（`LookupPair`），半角假名按 `cp = 0xFF61 + (c - 0xA1)` 映射——不引入 ICU/iconv，内核体量可控。

#### 4. 封面回写（核对缺口 #4 整改）
- `fmt_tag.cpp`：新增 `LoadCover`（FFD8FF→image/jpeg、89504E47→image/png）与 `BuildFlacPicture`（大端 u32 picture type 3 + mime + 空 desc + 尺寸四零 + dataLen + data）；`WriteFlacTags` 已有 type 6 块则替换（picReplaced 标志）无则追加，last 标志统一重排；`BuildId3v23` 加 APIC 帧（encoding 0x00 + mime NUL + type 0x03 + desc NUL + data），cover-only 也放行（any 标志）。
- `WriteAudioTags` 三参签名（`coverPath` 可选），napi `writeTags` argc=3，`.d.ts` 同步 `coverPath?: string`；`MaintenancePage` 新增「回写封面」勾选（默认关），无内嵌封面的曲目回写循环自动跳过。

## v1.5.0（2026-11-25，commit `b0d8907`）

**主题**：Pro 2.0 三项收官——DST 解压、SACD ISO 直读、文件标签回写。三项均真机验证通过，Pro 2.0 全部功能关闭。

**规模**：31 个文件变更，+3577 / −250 行；新增 4 个解码/格式源文件（fmt_dst、fmt_iso、fmt_tag、dsd_feed.h）约 1470 行 C++。

### 一、新增功能

#### 1. DST 解压（DFF 内 DST 帧真解码）
- 新增 `fmt_dst.cpp/h`：DST 算术解码器，接入 DFF 解码链；DFF 里标 `CMPR=DST` 的帧先经 DST 算术解码还原 DSD 位流，再走既有抽取链（`dsd_feed.h` 新增 210 行喂帧逻辑）。
- 实现依据 DSTD 规范自行推导，公开渠道拿不到参考编码器（ISO PAS 官网关停、RefEncoder 网盘失效）。
- 真机验证：`dsd-dst-1.dff`（450 帧全算术编码）播放日志 `opened DSD64→PCM(软解)·DST 88200Hz 1ch 1bit 6000ms`，rms=0.554；`dsd-dst-fir.dff`（10 帧 FIR 滤波帧）133ms 精确（10 帧/75fps）后自动接续下一首。

#### 2. SACD ISO 直读
- 新增 `fmt_iso.cpp/h`（562 行）：扫描期解析 ISO 的 MasterTOC / AreaTOC / SACDText / SACDTRL，把每条两声道曲目展开为虚拟曲目（uri 格式 `iso://<路径>#mwi:<index>`）；播放期扇区解复用 → DST/DSD 解码。
- 全部偏移按 `scarletbook.h`（sacd-ripper 头文件，`refs/` 存档）逐字段累加核实，修正了 PROTOCOL.md 两条旧记录（`area_1_toc_1_start` 实际在 @64、`track_text_offset` 实际在 @128）。
- 位序曾一度误判，靠三份一手证据（头文件 LE 位域声明序 + sacd-ripper LE 分支显式移位 + 注释）裁决后放弃"修复"，原实现正确。
- 真机验证：曲库出现 `Miwen Track A`，艺人行读出 ISO 内 SACDText（"Miwen Audio · Miwen SACD Test"），格式 "ISO · 88.2 kHz"，时长 00:06；点播日志 `opened SACD-ISO(DSD)→PCM(软解) 88200Hz 2ch 1bit 6000ms`，播放 rms 正常。

#### 3. 文件标签回写（维护页批量改索引标签增强）
- 新增 `fmt_tag.cpp/h`（507 行）+ napi `writeTags` 接口：维护页「批量改索引标签」勾选「同时回写到文件（FLAC/MP3）」后，改索引的同时把艺人/专辑写进文件本体——FLAC 写 Vorbis comment，MP3 写 ID3v2.3（v2.4 帧降级转换、TPE1 UTF-16），**音频流字节不动**；其他格式自动跳过并计数。
- 真机验证：Download 根目录 25 首，Toast「索引 25 条；回写：成功 2，跳过 23，失败 0」（23 个非 FLAC/MP3 正确跳过）。
- 失败路径如实报错不假成功：授权失效时同流程 Toast「失败 2（打不开文件（可能是目录授权未生效））」。

### 二、Bug 修复

1. **fmt_iso.cpp 三处编译错误 + 一个交付 bug（重大）**
   - 之前后台构建 exit 0 是**误报**——fmt_iso.cpp 从未编译通过。交叉编译设备端回归测试二进制（DevEco LLVM `--target=aarch64-linux-ohos`）抓出：
     - (a) `fmt_iso.h` 缺 `#include "decoder.h"`；
     - (b) SacdFeeder 的 `dst_` 成员与 DstDecoder 成员重名 → 改名 `dstEnc_`；
     - (c) SacdSource 全类使用 `info_` 却从未声明；
     - (d) PullFrame 交付用 `pendingDecoded_.data()` 类型错误，且堆叠帧会被 `clear()` 丢弃 → 改 `front()` + `erase(begin())`。
   - **教训**：TaskOutput 拿到的 exit 0 不可信，必须看到 BUILD SUCCESSFUL 原文。

2. **FLAC 回写块头 bug（真机验证抓出）**
   - `WriteFlacTags` 替换 VORBIS_COMMENT 块时只压入 3 字节长度、**漏掉 1 字节块头（last 标志 + type 4）**，导致元数据区整体错位：第二块被当 14597 字节的"STREAMINFO"、last 标志落到内容中间、mutagen 读回 `tags=None`。
   - 修复：替换分支补写块头字节。修复后重验：块结构 STREAMINFO+VORBIS_COMMENT+PADDING 正确、mutagen 正常解析、STREAMINFO 音频指纹（md5）不变、音频区逐字节一致。
   - MP3 分支无此问题（音频帧 sha256 一致）。
   - **方法论**：验证采用「mutagen 读标签 + 手写二进制块解析 + 音频区 sha256 逐字节比对」三重独立手段——此 bug 只有这样才抓得住。

3. **make_sacd_iso.py 两处**
   - s4 的第二个 packet info 误写到音频载荷后（应为与第一个连续排布在扇区头后）；
   - 验证公式两错（正弦均值应为 0 而非 (amp+1)/2；时长公式错）→ 改宽松均值平衡检查 + 正确时长换算。

4. **杂项**
   - `.gitignore` 追加 `tools/dsd_material/iso_parse_test`（设备端 ELF 不入库）。
   - `decoder.cpp` / `napi_init.cpp` 配套接线改动（writeTags 接口注册、解码链分发）。

### 三、素材与工具（`tools/dsd_material/`）

- `make_dst.py`（411 行）：自研 DST 编码器——区间法算术编码（寄存器语义镜像 fmt_dst.cpp），450+10 帧 roundtrip bit-exact；支持无预测帧（coeff=0）与 FIR 帧（coeff=8）。
- `make_sacd_iso.py`（361 行）：生成 SACD ISO 素材（2950 扇区 5.8MB，450 帧×5 扇区，双声道不同信号防接反），`verify_iso()` 镜像全部解析路径 bit-exact 通过。
- 测试素材入库：`dsd-dst-1.dff`（2,125,930 B）、`dsd-dst-fir.dff`（63,410 B）、`sacd-test.iso`（6,041,600 B）。
